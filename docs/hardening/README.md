# Härdning

**CIS Ubuntu Linux 26.04 LTS Benchmark v1.0.0 — Profil: Level 1 – Server**

Servern härdas enligt relevanta rekommendationer i CIS Benchmarks för Ubuntu 26.04. Endast rekommendationer på nivå Level 1 – Server tillämpas i detta projekt.

Arbetet är utfört av tre studenter som en del av ett LIA-projekt hos Systementor AB.

Varje rad har CIS-punkt, status, åtgärd, verifiering (kommando och resultat) och datum.
